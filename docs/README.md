# Documentation / 文档

- [English](en-us/README.md)
- [简体中文](zh-cn/README.md)

Documentation is organized by language first, then by purpose. Matching pages use
the same path beneath each language directory, without a repeated language suffix.
Keep user instructions in `guide/` and implementation, API and release operations
in `development/`. Retain historical release notes in `releases/` under their
original language. Temporary plans, debugging notes and acceptance evidence belong
in `.tmp/`, outside this documentation tree.

Five short compatibility entries remain at the old paths used by published plugin
packages. Their content points into the language trees; new documentation belongs
in those trees. Package archives, versions and checksums remain unchanged.

文档先按语言、再按用途组织。翻译页在各语言目录下使用相同路径，文件名不再重复语言后缀。
用户说明放在 `guide/`，实现、API 和发布运维说明放在 `development/`；历史发布说明在原语言的
`releases/` 下保留。临时计划、调试记录和验收证据放在 `.tmp/`，不进入正式文档目录。

已发布插件包使用的五个旧文档地址保留简短兼容入口，正文位于语言目录。
新增文档应直接放入语言目录；此次归档不修改插件安装包、版本和校验值。
