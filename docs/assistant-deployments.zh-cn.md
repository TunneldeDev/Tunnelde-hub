# 远端助手部署身份

[English](assistant-deployments.en-us.md)

远端助手源码部署会记录已保存主机的 ID 和连接时的 `user@host:port` 地址。复用与清理时，两者都必须
匹配。重新连接同一目标可使用等价 SSH 连接；修改已保存主机的地址，并不授权清理新机器上的文件。

删除会话时，每份部署记录（包括保留的旧部署）都按其自身的目标验证。目标断开或地址改变时，清理会
停止，保留会话和剩余归属记录；重新连接原机器后可重试。部署目录位于 `~/.TunneldeAI/Chats/`，不会
仅凭名称扫描删除其他文件。

旧记录可能没有地址。清理前会请你确认：显示的地址是否为拥有该目录的原机器。取消会保留文件和会话。
若同一主机 ID 对应多个不同地址，不会自动选择。在地址改变后的目标上重新部署，会使用新目录，避免
复用旧路径。

清理前会检查文件校验和与目录内容，但这些检查不能原子地防止其他客户端在删除期间改动文件。清理
运行时请避免编辑部署目录。身份绑定也不代表 CLI 进程能够跨应用重启持久运行。

## 恢复任务

恢复操作绑定保存的进程与任务，而非会话中最近使用的任意进程。开始新消息后，旧任务保留历史，但不再
提供恢复入口。过期操作会在访问进程或发送请求前被拒绝，同一远端 runner 被复用也不例外。检查当前
任务会展示可用性、状态，以及存在时的退出码和错误；检查不会启动 agent 或发送模型提示词。支持任务
运行身份的宿主还会发送操作时捕获的身份，防止旧入口选中同一 runner 上的新任务。

观察持久 runner 的活动任务时，只有宿主明确返回忙碌，才会退避重试状态或日志读取。读取始终使用同一
runner 身份和事件游标，共享 30 秒期限，最多尝试八次；取消同时终止待完成的读取和退避。权限错误、
断线和超时会直接返回；此观察器绝不重试启动、发送、审批或停止操作。手动检查仍只读取一次。

若持续忙碌或 runner 返回 `notFound`，会话转为中断并保留恢复身份。重新连接原主机、检查任务，再选择
继续，以观察已有日志。runner 不存在或响应丢失，都不能证明此前操作未执行，因此恢复不会重新发送
提示词。这些规则用于高级持久配置，不代表普通依赖 SSH 连接的 agent 进程也能跨断线保持运行。
