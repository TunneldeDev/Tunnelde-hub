# 持久运行器恢复

[English](../../en-us/development/runner-recovery.md)

实验性 `runners.*` API 将新部署绑定到保存的主机 ID、实际连接地址及握手时观测到的 SSH
主机密钥，重新连接时三者必须匹配。修改保存主机或接受另一个密钥不会改变既有任务的目标。

历史记录仍可读取，但检查与远端清理前需要通过原生确认核对原目标。更新插件不会自动将
旧任务交给新的包指纹。提供核对入口前，先通过 `api.describe` 确认支持 `runners.review`：

```js
const { reviewed } = await host.call("runners.review", {
  sessionId,
  runnerId,
  directory,
  kind: "destination",
});
```

`destination` 仅为尚未捕获身份的历史记录绑定原目标；`control` 请求将一条任务交给当前
已有授权的插件包。两者均需 `ssh.exec` 与原生确认，不接受调用方自行声明已确认。
取消返回 `{ reviewed: false }`；记录变化、撤权、连接变化或确认过期均不会应用更改。
已经绑定的目标不能覆盖。

交接保留原远端包与权限范围，不能交接已结束任务或清除停止请求，也不启动任务、发送
提示词或重放审批。成功交接后继续观察原任务身份，不要自动重新发送先前操作。

设置 → 插件 → 远端任务恢复允许用户无需启动插件或选择 Node，即可检查任务和请求停止，
包括插件已卸载或应用处于受限模式的情况。保存记录及 SSH 可用不代表进程正在运行。
移除任务记录要求已确认终态且无停止请求，远端文件保留。未知启动返回 `notFound` 不代表
退出。`runners.list` 保持原字段，目标身份与控制元数据仍为宿主私有信息。

## 部署中断

支持部署日志的宿主在远端修改前保存意图，区分目录创建待确认和上传未完成，只有确认完成后
才将部署标为可用。插件停止时，原生恢复页面仍可显示这些阶段。未完成部署不会出现在
`runners.list` 中，不能满足 `runners.start`，对同一目标调用 `runners.deploy` 会返回
`plugin.runners.deploymentIncomplete`。已有就绪记录和列表字段保持兼容。

请使用全新目录，并保留未完成恢复记录；不能根据远端路径存在推断归属或完成状态。
只有尚未提交远端修改的预留可经原生确认移除，目录创建及上传结果未知时不能自动移除记录。
有日志不代表远端残留已清理：软件不会递归删除部分部署目录，也不重放启动或消息。

部署前会捕获与已授权指纹一致的插件字节快照（上限 32 MiB），检查显式选择的原生 helper
（上限 64 MiB），拒绝与 helper 冲突的保留路径，并对上传文件采用排他创建。准备错误不会
产生远端修改，也不会隐式选择用户安装的 Node。

## 初始化配置

新的远端对话在部署前，通过 `api.describe` 查询 `runners.startInitialized`。
插件以 `remoteRunner.configuration: "initialize-v1"` 明确声明支持，声明绑定到
已批准且实际部署的字节。宿主另行查询所选辅助程序是否支持
`runner.initialize-config.v1`。宿主不支持或辅助程序查询失败时，不回退到配置文件；
应更新宿主或辅助程序，并在需要时明确部署到全新目录。历史任务的状态、停止、日志和
控制权交接规则保留。

新 RPC 参数为 `{sessionId, directory, configuration, secrets?}`。配置是至多
200 KiB 的对象，秘密是字符串映射，完整宿主请求上限为 256 KiB。辅助程序在完整
接收 stdin 信封后才创建任务，以 `remote-entry.mjs --initialize-config` 启动
子插件，通过 initialize 传递配置和秘密。子插件先校验包身份、配置协议策略和范围，
拒绝递归 SSH 目标及此模式下的环境变量秘密映射。存储不以启动配置播种；插件主动
保存和运行时行为仍可能落盘，不承诺任意代码永不保存，也不隐含清理。

旧的 `--config` 子插件入口继续兼容历史辅助程序和任务。普通直接 SSH stdio 执行
仍使用原有的独立适配器。

## 配置写入

支持配置日志的宿主将尚未提交、创建待确认、写入未完成和已保存与启动状态分别记录。
配置文件采用排他创建，在 OPEN 时设置 0600 权限，分块写入时检查授权与整条记录。
新的停止请求或运行时撤销可阻止延迟写入响应继续提交启动。所选 helper 协议和既有
`runners.list` 字段保持不变。

原生恢复界面展示阶段，不暴露配置值或秘密。任务已停止或 `notFound` 不能确认未知的
配置 OPEN、WRITE、CLOSE 已结束，这类记录不能移除。配置已保存不代表残留已清理，
明确移除符合条件的终态记录会保留远端文件。历史记录仍可读取，不推测其配置状态。
