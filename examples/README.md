# Plugin examples / 插件示例

Complete plugin examples live in this repository alongside the SDK. They are
local-install development material, not automatically published catalogue packages.
The application repository keeps only host tests and minimal protocol fixtures.

完整插件示例与 SDK 一起维护在本仓库，可用于本地安装和开发，不会自动发布到插件目录。
软件主仓库仅保留宿主测试及最小协议夹具。
