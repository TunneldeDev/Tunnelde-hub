# Text Checksum · 文本校验和

Calculate SHA-256 or SHA-512 of exactly the UTF-8 text entered, including line endings.

Open **Text Checksum**, enter a value (for example `Hello`), then choose **Calculate digest**. Requires Node.js 22 or later. No network, files, saved input or host permissions. Copying is always explicit.

按原样计算所输入 UTF-8 文本的 SHA-256 或 SHA-512，包括换行。打开插件页面，输入内容后点击「计算摘要」。需要 Node.js 22 或更高版本；不读取文件、不联网，也不保存输入。
