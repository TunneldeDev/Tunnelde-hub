# Studio Themes

Two themes for the Tunnelde workbench:

- **Cobalt Dusk** combines deep blue surfaces with a soft cobalt accent.
- **Porcelain** combines warm light surfaces with a restrained blue accent.

Install the package from the marketplace, a local folder, or a ZIP archive. Open its plugin details, then select **Apply theme** beside the theme you want. Both themes include workbench and terminal colors. Applying a theme takes effect immediately and replaces your current appearance, accent, and region color overrides; other preferences stay as configured. You can customize individual colors afterward in Settings → Appearance.

This is a pure theme package. It contains no executable entry point, commands, or views and needs no Node runtime or startup step. Installing the package does not change your current theme. Removing it leaves your selected colors in place.
